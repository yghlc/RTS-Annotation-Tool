Check Active RTS Expansion

A guide to the RTS Annotation Tool. You review the automated mapping of retrogressive thaw slumps (RTS) cell by cell — confirm whether each cell contains a real slump, correct the polygons where needed, and track how each slump's boundary expands across six years of Sentinel-2 imagery. Every confirmation, edit, and addition you make becomes ground reference for future mapping and model calibration.

Main Page

The screen has three working areas. Get oriented with these before you start.

Top bar

Global view toggles (Opacity, Show outlines, Fill, NIR, Hover preview), Reload, Undo / Redo, the cell counter #/total, and Jump-to-cell.

Left canvas

The year thumbnails, the large image with pre-drawn polygons, and zoom controls with a zoom lock.

Right panel

Progress and Yes / No / Unknown counts, the per-year instance list, the drawing Tool block, the cell Note, and the Validate-Result buttons plus Save / Skip / Prev / Next.

01

Verification workflow

  1. Open a cell. Use the year strip (or press 1–6) to step through the same area across years and watch how the slump changes.

  2. If the cell already has pre-drawn polygons (unconfirmed), check each one and act on it:

    • Drawn correctly→ select the instance and press Enter to confirm (or click its ✓ button).
    • Real RTS, but the position or shape is wrong→ adjust the boundary in Manual or Mouse mode.
    • Not a real RTS (false positive)→ delete the instance.
    • A real RTS the model missed (false negative)→ add one using the Drawing tools.

  3. Once every year and every instance in the cell is handled, click the cell-level result button, then Save.

02

Cell result & navigation

Confirmed Correct RTS

The cell contains a real RTS and the polygons are accurate. Confirms and saves the polygons for all years.

No RTS

The cell contains no real RTS. Clears the polygons in every year.

Unsure

Image quality is poor or the case is ambiguous. Leaves it flagged for later review.

Save / Skip / move on. Save (S) writes your decision; Skip (Space) passes the cell without a verdict; ← Prev / Next → (← / →) move between cells. Use Jump to # in the top bar to go straight to a cell number.
03

Drawing tools

SAM

Place Include (F) points inside the slump and Exclude (B) points outside it; the SAM model segments the boundary from those prompts. A few well-placed points usually beat many. Clear points drops the current prompts; Clear removes polygons.

All Years — points added on any year sync to the others and segment all six boundaries at once; This Year — segments only the current year. Matching this: Clear under All Years removes every year's polygon, under This Year only the current one.
Manual

Click to add a vertex, double-click to close the polygon, Esc to cancel. Best when the model isn't helping and you want to trace the outline by hand.

Mouse

Edit an existing polygon: left-click adds a vertex, right-click deletes the hovered vertex, and drag moves one. Delete removes the hovered vertex, or the whole instance if you're not over a vertex.

Remember

Finish one RTS before starting the next. After you draw or segment an instance, mark it complete by clicking its ✓ in the left instance panel (or pressing Enter). Only then begin drawing the next one — otherwise new points keep editing the current instance.

Same ID

The same ID must refer to the same slump in every year, so an instance's polygons trace one slump changing over time — not different features. If the automatic ID is wrong, edit the ID field in the instance panel by hand to keep it consistent across all years.

04

View & instance controls

Top-bar toggles change how the imagery and polygons are drawn — they never change your data.

OpacityBlends the imagery under the polygons so you can see the ground beneath an outline.
Show outlinesToggles the polygon outlines on or off.
FillFills each polygon with a translucent tint instead of showing only its outline.
NIRSwitches to the near-infrared composite, where fresh disturbance often stands out more clearly.
Hover previewPreviews an instance when you hover over it in the list.
Zoom · lock− / + / RESET control zoom; the lock (🔒) keeps the same zoom and pan when you switch years so frames stay aligned.
ReloadReloads the current cell from the server, discarding unsaved local edits.
ThumbnailsA green border means that year already has a segmentation; the small badge is its instance count. The last thumbnail is an animated GIF of all years.
Instance panelEach instance shows its Area (ha / m²), a per-instance Note, and Delete / confirm (✓) buttons. The right panel also tracks overall Progress and Yes / No / Unknown counts.
